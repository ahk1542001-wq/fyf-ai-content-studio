> **LEGACY PROTOTYPE DOCUMENTATION**
> This document describes the earlier mock prototype and is preserved only as migration evidence. It is not the current FYF AI V1 architecture.

1. Start the app with `npm run dev`.
2. Confirm the dashboard opens on Content Pipeline.
3. Switch from `FYF AI Trading` to `Star Digital Agency`, then back.
4. Enter a topic in the Composer.
5. Click `Generate` and confirm Burmese draft text appears.
6. Add risky wording such as `အမြတ် အာမခံ`.
7. Confirm Risk Guard shows a blocked issue.
8. Click `Apply safer AI Fix`.
9. Click `Approve`, then `Mock Publish`.
10. Open `Integrations`, test a demo connection, then open `Logs`.
